🎯 Catch the Falling Objects Game


🎮 About the Game
A fun and simple JavaScript game where objects fall from the sky, and your goal is to catch them by clicking!
Each successful catch earns you points. Missed objects vanish after a few seconds — so be quick!

🎯 How to Play
Objects will fall randomly from the top.

Click on an object to catch it and earn 1 point.

Objects disappear after 5 seconds or when they reach the bottom.

Catch as many as you can!
